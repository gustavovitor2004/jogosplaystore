# Jogos Play Store — Claude Studio

Repositório central dos jogos de um desenvolvedor individual para a Google Play Store.

**Prioridades:** desempenho, compatibilidade (Android 7.0+ / API 24, aparelhos fracos) e segurança.

## Estrutura
```
/jogos/<nome-do-jogo>   RELATORIO.md, design/, codigo/, security/
/security-foundation    base de segurança reutilizável entre todos os jogos
/ideias/backlog.md      ideias em avaliação e pra depois
```
